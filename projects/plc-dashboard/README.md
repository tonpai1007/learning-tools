# PLC Simulator + Automation Dashboard

A portfolio project demonstrating industrial automation knowledge:
- PLC ladder logic simulator in Python
- Dashboard with real-time monitoring
- LINE notification integration

## Structure

```
plc-dashboard/
├── plc_simulator.py      # PLC logic simulator
├── api_server.py          # FastAPI backend
├── dashboard/             # Next.js frontend
├── requirements.txt
└── README.md
```

## Quick Start

```bash
python plc_simulator.py
```

## Projects Included

1. **Motor Control** - Start/stop with seal-in circuit
2. **Conveyor Counter** - Batch counting with sensors
3. **Traffic Light** - Sequential state machine
